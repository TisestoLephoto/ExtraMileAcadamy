# ExtraMile Academy Website

A multi-page HTML/CSS website for ExtraMile Academy.

## Pages
- index.html — Home
- about.html — About the academy
- services.html — Services and subjects
- pricing.html — Pricing and packages
- team.html — Our team
- contact.html — Contact/enquiry form
- enrol.html — Enrolment form

## Styling
All styling is stored separately in:
`css/style.css`

There is no CSS embedded in the HTML files.

## How to run
Open `index.html` in a browser. The navigation links connect the separate pages.

## Important
The contact and enrolment forms are front-end templates. They need a backend, Formspree, Netlify Forms, email service, or another form-processing service before they can actually send submissions.
